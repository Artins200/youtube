# YouTube Local — локальное мобильное приложение

Мобильное приложение-плеер, которое **на 100% повторяет визуальный стиль мобильного YouTube**:
главная лента с рекомендациями, Shorts, страница просмотра с красным прогресс-баром,
пилюлями «Нравится / Поделиться / Скачать / Сохранить», комментарии, подписки,
история, тёмная и светлая темы.

При этом это **не сайт с чужими видео** — здесь нет никакого контента из интернета.
Вы загружаете **свои** видео, называете их как угодно, смотрите — и они **случайным
порядком** появляются в рекомендациях.

## Главное

- **Всё абсолютно локально.** Видеофайлы, превью, названия, описания, комментарии,
  лайки, история просмотров хранятся только на вашем устройстве (IndexedDB).
  Приложение ничего не загружает в сеть и работает без интернета.
- **Это приложение, а не сайт.** Устанавливается на телефон через
  «Установить / На экран «Домой»», запускается на весь экран без адресной строки.
- **Рекомендации рандомные.** Каждое открытие главной ленты — новая случайная
  раскладка ваших видео; после окончания видео автоматически запускается
  следующее из рекомендаций.

## Как установить на телефон

1. Откройте адрес приложения в браузере телефона (один раз нужен интернет,
   чтобы загрузить сам интерфейс — он кэшируется и дальше работает офлайн).
2. Дождитесь появления кнопки **«Установить как приложение»** на вкладке **«Вы»**
   (или откройте меню браузера → **«На экран «Домой»»** / **«Установить приложение»**).
3. Готово — на экране появится значок YouTube, приложение открывается как обычное
   мобильное приложение и полностью работает без интернета.

## Как пользоваться

| Кнопка | Что делает |
| --- | --- |
| **+** (нижняя панель) | Загрузка видео с телефона: выбираете файл, пишете **любое название** и описание |
| **Главная** | Лента рекомендаций — ваши видео в **случайном порядке** (повторное нажатие перетасовывает) |
| **Shorts** | Вертикальные видео в полноэкранной ленте со свайпами |
| **Подписки** | Все ваши видео от новых к старым |
| **Вы** | История, ваши видео, «Смотреть позже», настройки, установка приложения |

- Тап по видео — открыть страницу просмотра (как в YouTube: плеер, метаданные,
  пилюли действий, комментарии, рекомендации).
- В плеере: один тап — управление, **двойной тап слева/справа — перемотка ±10 сек**,
  перетаскивание красного прогресс-бара, скорость воспроизведения, полный экран.
- Комментарии, лайки, «Смотреть позже» — всё сохраняется локально.
- Скачать — сохранить исходный файл видео в «Загрузки» устройства;
  «Поделиться» — отправить файл штатным меню телефона (если поддерживается).

## Локальный запуск на компьютере

```bash
cd app
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Структура проекта

```
app/
  index.html            — разметка и SVG-спрайт иконок в стиле YouTube
  styles.css            — стили мобильного YouTube (светлая/тёмная темы)
  app.js                — лента, плеер, Shorts, загрузка, поиск, настройки
  db.js                 — локальное хранилище IndexedDB
  sw.js                 — service worker: офлайн-кэш интерфейса
  manifest.webmanifest  — манифест PWA (установка на телефон)
  icons/                — иконки приложения
tools/make_icons.py     — генератор иконок (Python, без зависимостей)
```

Приватность: приложение не содержит аналитики, трекеров и внешних запросов.
Единственное место хранения — память вашего устройства.
